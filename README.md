### 🚀 Featured Test Automation Projects

#### 1. 🛍️ [SauceDemo Hybrid (UI + API) Test Automation Framework](https://github.com/myasiru/saucedemo-playwright-hybrid-framework)
> A production-grade Hybrid Test Automation Framework built with **Playwright & TypeScript**.

- **Key Highlights & Architecture:**
  - **Fast API Login Bypass:** Accelerates UI test execution by injecting session cookies via API context.
  - **Page Object Model (POM) + BasePage:** Scalable inheritance structure for maximum code reusability.
  - **Component Pattern:** Isolated reusable UI components (`NavbarComponent`, `FilterComponent`).
  - **Comprehensive API Suite:** Integrated with ReqRes API covering positive, negative, and edge cases.
  - **CI/CD Integration:** Parallel execution via GitHub Actions with HTML artifact reporting.
